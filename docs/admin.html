Set up login

  1. On GitHub open Settings → Developer settings → Personal access tokens → Fine-grained tokens and generate a new token.
  2. Repository access: Only select repositories → elvin-jhon-portfolio.
  3. Permissions → Repository → Contents: Read and write. Nothing else.
  4. Paste the token below and choose a password. The token is encrypted with that password before it is saved; only the password can unlock it.

At least 12 characters. The encrypted token lives in a public repo, so this password is the only lock: make it long and unique.
